# COSMOS // Chronicles of Deep Space 🌌

> Интерактивный 3D-эксплорер глубин Вселенной: сверхмассивная черная дыра «Гаргантюа», релятивистское замедление времени, квантовая сетка пространства-времени, экзопланеты и гиперпространственный прыжок.

![COSMOS Preview](favicon.svg)

## ✨ Особенности
- **Интерактивная 3D-обсерватория (Three.js + WebGL)**: вращение на 360°, переключение небесных тел (Черная дыра, Земля, Сатурн, Kepler-452b, Пульсар).
- **Варп-прыжок (Hyperdrive Jump)**: звездные треки со вспышкой и динамическим растяжением угла обзора FOV камеры.
- **Лаборатория замедления времени (Time Dilation Lab)**: расчет гравитационного и релятивистского замедления по уравнениям ОТО и СТО Эйнштейна с живыми двойными часами.
- **Интерактивная сетка пространства-времени**: реакция на курсор мыши, образование гравитационной воронки и искривление траекторий фотонов.
- **Космический синтезатор (Web Audio API)**: генеративный глубокий космический эмбиент без внешних MP3-файлов.
- **Консоль связи (METI)**: отправка кодированного двоичного радиосигнала к системе TRAPPIST-1 на частоте 1.420 ГГц.

## 🛠️ Стек технологий
- **HTML5 & Vanilla CSS3**: темная космическая тема, Glassmorphism, кибернетический HUD-интерфейс.
- **Three.js**: 3D-сцены, шейдеры, частицы, освещение и материалы.
- **GSAP**: кинематографические переходы камеры и анимации интерфейса.
- **Web Audio API**: процедурный звук и эмбиент.

## 🚀 Локальный запуск
```bash
# Клонировать репозиторий
git clone https://github.com/ruekdp/cosmos-chronicles.git

# Перейти в папку проекта
cd cosmos-chronicles

# Запустить локальный сервер
npm run dev
# или
npm start
```
Откройте в браузере: `http://localhost:3000`
